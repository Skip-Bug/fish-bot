# 🐟 Fish Shop

## 📖 Описание

Telegram-бот для заказа рыбы и рыбных продуктов. Пользователи просматривают каталог,
добавляют товары в корзину и оформляют заказ — всё прямо в Telegram.
Управление каталогом и данными через Strapi CMS.

## 🧰 Требования

- 🐍 **Python 3.10** (на остальных версиях не тестировалось).

  Проверить версию:

  ```bash
  python --version
  ```

- 🟥 **Redis** ([локально](https://redis.io/download/) или [удалённо](https://redis.com/redis-enterprise-cloud/)).

  Проверить, что запущен:

  ```bash
  redis-cli ping
  # → PONG
  ```

- 🌐 **Strapi CMS** — отдельный сервис, может быть на удалённом хосте.

  По умолчанию бот ожидает Strapi на `http://localhost:1337`. URL задаётся переменной `STRAPI_URL` в `.env`.

## ⚙️ Переменные окружения

Создайте файл `.env` в корне проекта:

```env
TG_BOT_TOKEN=ваш_токен_телеграм_бота
REDIS_URL=redis://localhost:6379/0
TG_PROXY_URL= # если нужно проксирование
STRAPI_URL=http://localhost:1337
```

| Переменная     | Описание                                                                                                                                                 | По умолчанию               |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------- |
| `TG_BOT_TOKEN` | [Токен Telegram-бота](https://way23.ru/%D1%80%D0%B5%D0%B3%D0%B8%D1%81%D1%82%D1%80%D0%B0%D1%86%D0%B8%D1%8F-%D0%B1%D0%BE%D1%82%D0%B0-%D0%B2-telegram.html) | —                          |
| `REDIS_URL`    | URL подключения к Redis                                                                                                                                  | `redis://localhost:6379/0` |
| `TG_PROXY_URL` | Прокси для Telegram API                                                                                                                                  | `socks5h://127.0.0.1:1010` |
| `STRAPI_URL`   | URL Strapi CMS                                                                                                                                           | `http://localhost:1337`    |

Файл `.env` **не попадает в git** — у каждого разработчика свой.

## 🧱 Установка

**📦 Установите зависимости Python:**

```bash
pip install -r requirements.txt
```

**📦 Установите зависимости Node.js (для Strapi):**

```bash
cd fish-cms
npm install
```

## 🗄️ Модели Strapi CMS

Бот работает с 4 моделями Strapi. При развёртывании CMS создайте эти модели с указанными полями и связями.

### Product (Товар)

| Поле          | Тип     | Описание                                  |
| ------------- | ------- | ----------------------------------------- |
| `title`       | string  | Название товара, уникальный, обязательный |
| `description` | text    | Описание                                  |
| `price`       | decimal | Цена, >= 0, обязательный                  |
| `picture`     | media   | Изображение товара                        |

### Client (Клиент)

| Поле          | Тип    | Описание                                      |
| ------------- | ------ | --------------------------------------------- |
| `external_id` | string | Уникальный ID пользователя (Telegram/chat ID) |
| `email`       | email  | Email клиента                                 |

### Cart (Корзина)

| Поле          | Тип      | Описание                             |
| ------------- | -------- | ------------------------------------ |
| `external_id` | string   | ID пользователя для привязки корзины |
| `client`      | relation | Связь с Client (many-to-one)         |
| `cart_items`  | relation | Связь с CartItem (one-to-many)       |

### CartItem (Позиция корзины)

| Поле       | Тип      | Описание                      |
| ---------- | -------- | ----------------------------- |
| `quantity` | decimal  | Количество (кг)               |
| `product`  | relation | Связь с Product (many-to-one) |
| `cart`     | relation | Связь с Cart (many-to-one)    |

### Схемы связей

```
Client (1) ────< Cart (N) ────< CartItem (N) >─── Product (1)
```

**Важно:** бот использует эти модели и связи для работы каталога, корзины и оформления заказов. Если модели отличаются — бот работать не будет.

## 🚀 Запуск

**1. Запустите Strapi CMS (если не используете удалённый хост):**

```bash
cd fish-cms
npm run develop
```

Страница админ-панели: `http://localhost:1337/admin`.

> 📦 Код Strapi находится в папке `fish-cms/`. В продакшене Strapi может быть на отдельном хосте — тогда этот шаг пропускается.

**2. Запустите Telegram-бота:**

```bash
python tg_bot.py
```

## 🎮 Как пользоваться

- **/start** — главное меню с каталогом товаров.
- **Выбор товара** — название, описание, цена и фото.
- **Добавить в корзину** — товар добавляется на 1 кг.
- **🛒 Моя корзина** — просмотр и очистка корзины.
- **Оплатить** — оформление заказа (для новых клиентов запрашивается email).
